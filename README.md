# 📖 Overview

ClinNote AI is an AI-powered psychiatric documentation platform designed to help psychiatrists, therapists, psychologists, counselors, and behavioral health professionals generate structured clinical notes efficiently.

The platform transforms raw therapy or psychiatric session information into professional documentation formats within seconds.

Supported note formats:

- SOAP Notes
- DAP Notes
- BIRP Notes
- GIRP Notes

ClinNote AI helps reduce documentation fatigue, improve consistency, and streamline behavioral healthcare workflows.
